# 🍷 Квиз «Угадай сорт винограда»

Небольшой интерактивный квиз на React + Vite: угадывай сорта винограда по описанию, следи за таймером и читай мотивирующие цитаты после раунда. Также есть «Винная карта» с краткой справкой по популярным сортам.

## ✨ Что умеет проект

- **3 случайных вопроса** из пула в 24 вопроса (каждый раз почти новый набор).
- **Таймер на 60 секунд** на весь раунд.
- **Случайные цитаты** после результата — они разные при каждом прохождении.
- **«Винная карта»**: карточки с сортами и их кратким описанием.
- Адаптивная верстка: удобно играть и на компьютере, и на телефоне.

## 🎮 Как играть

1. Нажми «Начать викторину».
2. У тебя есть 60 секунд, чтобы ответить на 3 вопроса.
3. После раунда увидишь счёт и случайную цитату.
4. Загляни в «Винную карту», чтобы освежить знания.
